Frequently asked questions

I already use free programs. Why switch?

The free ones are great, each at one thing, and you can keep using them. Iron Check brings what you use at the counter into one place, in English and Portuguese, and does what they do not: tests USB ports, webcam, microphone and speakers, installs the network driver without internet and issues a PDF report with the service order and a file authenticity check.

How do the trial and the subscription work?

Ask for a trial key on WhatsApp: it lasts a few days and unlocks the full program. To subscribe, you pay monthly by Pix (Brazil's instant payment), send the receipt and get your key, which works on several computers. For the price, just ask on WhatsApp.

What do I download: the program or the kit?

The program (Iron-Check-Portatil.exe, 92 MB) already opens by itself. The full kit also brings the drivers folder, with the network driver library the program uses to install without internet. Extract the kit and leave the drivers folder next to the .exe.

Do I need to install it?

No. You open the file from any folder or from the USB drive. The first time it prepares its files in a folder next to it; after that it opens fast. The key and settings stay in that folder, not on the customer's computer.

Will it delete anything from the customer's device?

The tests do not. The disk scan only reads, the performance test uses a temporary file that is deleted at the end, and Boot Creator only touches USB drives (and warns that it erases the drive). The few tools that change Windows ask for confirmation and keep the original value or a copy.

Why does Windows warn about an “unknown publisher”?

It is the normal SmartScreen warning for new programs: click More info and then Run anyway. The administrator prompt is normal too: Windows requires it to read disk health and temperature and to install drivers.

What if the internet goes down?

The program keeps working for up to 24 hours on the last confirmation. After that, without being able to check, it stays locked until the license is confirmed. Your files are never deleted.

Can I share my key?

It is for your repair shop's use. The server records the computers and the approximate location of each use, and use by many people is detected: the key can be blocked.

Which computers does it run on?

Windows 10 or 11, 64-bit, on laptops or desktop PCs. Battery, touchpad and charger tests only make sense on a laptop. The tests work with any graphics card; overclock, detailed readout and video driver installation are for NVIDIA GeForce.
