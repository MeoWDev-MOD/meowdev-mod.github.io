How to install

Ready to use in a few minutes

Download the installer

Click “Download for free” and save BancadaSync-Setup.exe.

Install

Double-click it and follow the wizard. If Windows warns you, click More info and then Run anyway. No administrator password needed.

Create your shop

Open BancadaSync. On the first screen, enter the shop's details and create your user and password. Done.

Frequently asked questions

Why does Windows show a warning when installing?

The installer does not have a paid digital signature yet (the “verified publisher” certificate), so SmartScreen shows “unknown publisher”. The file is the same one published here; check its integrity with the hash below.

Where is my data kept?

On your computer, in %APPDATA%\CRM Assistencia. When uninstalling, the program asks whether you want to delete the data; the default is to keep it.

Do I need internet?

For day-to-day work, no. Only for features that depend on it, such as WhatsApp in the Pro version.

What if the computer shuts down?

When it turns back on, open the BancadaSync shortcut: your data and logins come back as they were.

How do I update to a new version?

Run the new installer over it. It closes the system, replaces the files and keeps your data.

How do I check that the file is the original? (SHA-256 of version 1.0.0)

1d10463c9d5ac24ce16623b04e5573c4cbf718de99053cb7d86f108681689fa7
In PowerShell: Get-FileHash .\BancadaSync-Setup.exe -Algorithm SHA256
